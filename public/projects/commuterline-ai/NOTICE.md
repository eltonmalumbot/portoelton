# Data geografis KRL — atribusi

- `krl.ts` dan `tracks.json` berasal dari proyek [mini-jabodetabek](https://github.com/stndaru/mini-jabodetabek) oleh Stefanus Ndaru Wedhatama (2026), berlisensi **MIT**.
- `tracks.json` disusun dari relasi rute **OpenStreetMap**. © OpenStreetMap contributors, data tersedia berdasarkan **ODbL**: https://www.openstreetmap.org/copyright
- Koordinat dan geometri untuk visualisasi, bukan posisi GPS live, bukan data operasional KAI. Versi ini mengikuti dataset jaringan sumber dan mungkin belum mengikuti revisi jalur/stasiun terbaru.
- Peta dasar: © OpenStreetMap contributors, via https://tile.openstreetmap.org (kebijakan penggunaan tile: https://operations.osmfoundation.org/policies/tiles/). Leaflet © Volodymyr Agafonkin / contributors (BSD-2-Clause).
