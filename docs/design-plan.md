# Portfolio refinement

Kind: software engineering portfolio; editorial service presentation of real engineering work.
Direction: neutral paper / forest ink, serif display + system sans, sharp edges, quiet hover motion.
Source baseline: main 32bb44c. Taste Skill 2.5.0 installed locally with `npx skills add Leonxlnx/taste-skill`.

- Hero: engineering identity, real portrait, location, one work action and a GitHub link.
- Recent work: two latest published case studies, existing source-based covers; no simulated app screens.
- Catalog: all published projects, full search, category and live-demo filters; previews load on request.
- Capabilities: existing skills in a compact, ruled index.
- About: existing role, biography and professional facts.
- Credentials: all published certificates and their verification links.
- Contact: existing contact destinations and social links.
- Case studies: existing narrative, galleries, live demos, stacks, roles and outcomes; architecture and evidence section for Handoff Hub and PeopleLens.

The explicit brief takes priority over generic skill recipes: preserve all projects, credentials, real contacts, captions identifying process artwork, existing routes and Next.js architecture. Catalog and case-study sections use content-driven heights so no content is cropped or removed to meet a fixed screen quota. No stock imagery, invented UI, shader decoration, forced animation, or template asset bundle. The skill's browser check findings that depend on its starter classes or fixed screen layout must be documented separately from real accessibility and layout defects.
